# dsh-focus-brief

一个 DSH 插件：**优化 agent 助手返回的结果与展示格式**。

它注册一个平行会话视图「专注」——切过去之后，每一轮是你输入的原话（官方那条蓝底黑字气泡，一字不改）
加上一张结果卡：标题与状态、白底回答区（一句结论，点开换全文）、默认收起的信息块
（展开整摞只铺开标题行，再点哪一块才出哪一块的内容）
（需要你确认 / 关键数据 / 产出文件 / 结论建议 / 风险提醒）。卡片上**不带执行日志**
（工具调用时间线仍在官方「轨迹」视图里），也不额外调用模型。

**骨架写死在本地，内容由模型按同一份回答格式契约填**——契约文本（320 字符）写进模型本来就要产出的
那条回答里，本地再按同一份规格解析：「契约是接口，本地是解析器」。

## 仓库结构：整个仓库就是这一个插件

```
.
├── index.js            # 宿主半：两条会话投影 + 回答格式契约 + 契约解析器
├── client.js           # 客户端半：专注视图的座位、卡片渲染、自己的极简 markdown 渲染
├── cordis.patch.yml    # bundle patch
├── package.json        # 插件清单（dsh.bundle / dsh.client）
├── preview.html        # 不用开 DSH 也能看的独立预览（真实数据 + 真实主题 token）
├── scripts/            # 全部验证脚本（可复跑；`node scripts/<name>.mjs`）
├── .tmp/               # 一次性中间产物（截图、抽取的主题包、语料普查脚本）——已 gitignore
├── LICENSE             # Apache 2.0
├── README.md           # 本文件：这是什么、怎么装、结构
└── MANUAL.md           # 实现与验证手册：卡片结构、契约与解析器、闸门、实测数字、边界
```

**安装**（安装目标就是本仓库根目录）：

```
plugin_manager { action: "install_bundle", target: "<本仓库根的绝对路径>" }
```

不想装也能先看效果：双击 `preview.html`。

## 它长什么样

```
        ┌───────────────────────────────────────┐
        │ 你输入的原话（官方那条蓝底黑字气泡，原样）  │
        └───────────────────────────────────────┘
┌ 卡片（回答）──────────────────────────────────────────┐
│ ● 契约标题（模型给的【本轮】/ 拿不到就「第 N 轮」）   [完成] │
├ 回答区（白底，留在卡片里）──────────────────────────┤
│ 一句结论（最多两行）      ← 点「展开回答全文」换成全文      │
├ 信息块（收起叠压成一摞；展开只铺开标题行，内容再点那一块才出）──┤
│ ? 需要你确认   2 条   ← 唯一“看完必须动手”的块，永远排第一  │
│ ▦ 关键数据 / 产出文件 / 结论建议 / ! 风险提醒              │
└ 底部：时间 · 工具调用次数 · 正文 N 字 · 继续追问 ──────────┘
```

选一个会话，点标题栏的**「专注」**标签即可；两边互不干扰，随时能切回「对话」。

## 详细文档

- [`MANUAL.md`](MANUAL.md) —— 卡片结构、契约与解析器的全部规则、每一条回归闸门与它的实测数字、
  已知边界、重启刷新后的验收清单。
- [`preview.html`](preview.html) —— 独立预览：6 轮真实数据 × 3 种状态，顶部可切换浅/深主题与白/灰页面底色。
